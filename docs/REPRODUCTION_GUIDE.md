# Reality Compiler — Reproduction Guide

This guide reproduces the core Reality Compiler results from a fresh checkout.

The repository contains both:

1. frozen result artifacts used in the submission, and
2. scripts for independently rerunning the evaluation.

Some steps require OpenAI API access. Formal solver and verification steps do not.
